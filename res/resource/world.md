res/resource/ 是游戏资源配置目录，用于定义游戏中的场景/世界配置表。

world.csv 字段说明

┌───────────────┬─────────────────────────────────────────┐
│     字段      │                  含义                   │
├───────────────┼─────────────────────────────────────────┤
│ Id            │ 场景唯一ID                              │
├───────────────┼─────────────────────────────────────────┤
│ Name          │ 场景名称                                │
├───────────────┼─────────────────────────────────────────┤
│ Init          │ 是否初始场景（1=是，0=否）              │
├───────────────┼─────────────────────────────────────────┤
│ Type          │ 场景类型                                │
├───────────────┼─────────────────────────────────────────┤
│ AbPath        │ 场景资源路径（如 scenes/login）         │
├───────────────┼─────────────────────────────────────────┤
│ ResName       │ 资源名称                                │
├───────────────┼─────────────────────────────────────────┤
│ UiResType     │ UI资源类型                              │
├───────────────┼─────────────────────────────────────────┤
│ PlayerInitPos │ 玩家初始坐标 (x, y, z)，非初始场景为 -1 │
└───────────────┴─────────────────────────────────────────┘
